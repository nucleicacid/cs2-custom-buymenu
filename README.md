# CS2 Custom Buy Menu
A modular, free-to-use buy menu for your Counter-Strike 2 custom maps.

## Installation
1. Navigate to `Steam\steamapps\common\Counter-Strike Global Offensive\content\csgo_addons\your_map`
2. Add scripts to their respective folders
3. In Hammer, create a **point_script** object and connect it to `maps/scripts/buymenu.vjs`
4. Create a **custom_hud_layout** object named *'buymenu'* and connect it to `panorama/layout/custom_game/buy_menu.vxml`
